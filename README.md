# 一键启动 (One-Click Launcher)

一个给 Windows 用的小工具：**一次点击，按你设定的顺序与间隔，依次启动多个任意程序（软件、脚本、快捷方式均可）**&#8203;。

纯 Python 标准库写成，**不需要安装任何第三方包**。

---

## 它能干什么

- 📋 **清单管理**：把任意程序加进列表，勾选是否参与「一键全启」
- ⏱ **按顺序 + 间隔启动**：例如「先开 A → 等 40 秒 → 再开 B」，适合有先后依赖的场景（如先起服务再开客户端）
- 🚦 **运行状态**：实时显示每一项是否在跑
- 🛑 **一键全停**：把这一轮启动起来的进程整棵进程树一起关掉
- 📥 **缩到托盘**：关窗口不等于退出，安静待在右下角；托盘菜单可重建桌面快捷方式
- 💾 **记住窗口**：位置和大小自动保存，下次打开还是你习惯的样子
- 🔒 **单实例**：重复双击不会产生第二个进程，只会把已有的窗口叫出来
- 🗂 **多类型**：`.exe` `.lnk` `.bat` `.cmd` `.py` `.pyw` `.js` `.ahk` `.ps1` 都支持

## 怎么用

### 1. 准备环境

- Windows 10 / 11
- Python 3.8 以上（[官网下载](https://www.python.org/downloads/)，安装时记得勾选 `Add python.exe to PATH`）

> 脚本支持的类型里，`.js` 需要额外装 Node.js，`.ahk` 需要额外装 AutoHotkey。

### 2. 启动

双击 `一键启动.bat`。它会自动寻找 `pythonw.exe`（支持安装到任意盘符），找不到再回落到系统 PATH。

### 3. 添加条目

点【添加】→【浏览…】选中你要启动的程序（软件、脚本、快捷方式都行） → 起个名字 → 设置「启动后等待」秒数。

### 4. 排好顺序

用【上移】【下移】调整：**把需要先就绪的程序排前面**（例如先起服务/主程序，再开依赖它的客户端），中间留足等待时间。

### 5. 开跑

勾选「一键全启」列的勾 → 点【一键全启】。

## 关于等待时间

这是最容易踩坑的地方：**部分程序从进程出现到真正就绪（如进入界面、完成初始化），通常需要 20~40 秒**。排在后面的程序若启动太早，可能连不上或报错。

建议第一次给 **40 秒**，跑顺了再逐步往下调。

## 文件说明

| 文件 | 作用 |
|---|---|
| `launcher.py` | 主程序 |
| `一键启动.bat` | 双击入口 |
| `icon.ico` / `icon.png` | 图标（窗口 / 托盘 / 任务栏各用其一） |
| `config.json` | 你的清单，**自动生成，不会上传** |
| `settings.json` | 界面偏好，**自动生成，不会上传** |
| `config.example.json` | 示例配置：复制后改名成 `config.json`，照着里面的字段填自己的条目 |

## 界面预览

从上到下：按钮区（宽度随窗口自适应）→ 项目列表 → 运行日志 → 右下角「自动最小化」开关。
窗口拉宽拉窄按钮跟着伸缩；窗口变矮时**优先压缩日志区**，保证列表还能看全。

## 一些实现细节

- 托盘图标用的是 `ctypes` 直接调 Win32 `Shell_NotifyIconW`，没有用任何 GUI 第三方库
- 所有 Win32 函数都显式声明了 `argtypes` / `restype`，否则 64 位下 `lParam` 传参会溢出
- 停止进程用 `taskkill /PID x /T /F`，连同子进程一起收掉
- 通过 `AppUserModelID` 让进程独立成一列，否则任务栏会把它的图标算到 Python 头上
- 单实例靠命名互斥体（`CreateMutexW` + `ERROR_ALREADY_EXISTS`）
